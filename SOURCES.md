# Sources — a link list

Every shipped module of *Calculemus*, with links to the digitized sources its edition
was made from. The prose statement of each edition lives in the `quelle` field of the
module's `data/<work>.json` and, with licensing detail, in [LICENSES.md](LICENSES.md);
this file adds the links. Where a module carries a working translation made for this
site, that translation has no external source — cite the original.

Links point to the exact scan, transcription, or eBook named in the edition statement
wherever one exists online; entries marked *documentation* are editions consulted or
cited for the record, not carried as text.
